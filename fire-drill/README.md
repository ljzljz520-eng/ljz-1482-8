# 消防演练脚本排练工具

用于消防演练的**脚本编排、审核、现场排练组织与离线播放**。
**只做组织排练与内容呈现，不连接、不控制任何真实消防设施**（火灾报警、喷淋、排烟、应急广播等）。

## 启动

```bash
cd fire-drill
npm start            # http://localhost:8080
# 可选：HOST_STALE_MS=3000 npm start  调短主持端崩溃接管等待（默认 15 秒）
```

零数据库依赖，数据持久化在 `data/db.json`（原子写入）。删除该文件重启会重新生成含
「报警 / 疏散 / 集合 / 复盘」四阶段的示例脚本（v1 已批准、v2 为责任人变更草案）。

## 六个页面

| 页面 | 职责 |
|---|---|
| 脚本编排 | 角色与责任人、四阶段动作时间线、**阶段条件（人工放行 gate）**、资源依赖、切换点、人工核对项；草案可编辑/删除 |
| 审核版本 | 草案 → 提交审核 → 签字批准/驳回；版本 diff（责任人/依赖/条件）；导出离线包与清单 |
| 主持端 | 获取唯一推进权、暂停/人工放行恢复、进入阶段、强制推进（理由留痕）、计划版本切换、备注、导入离线确认 |
| 现场设备 | 在线跟随主持端；断网显示**暂定阶段**与缓存时间；确认暂存本机，重连自动补报；下载/打开离线播放包 |
| 台账 | 已执行（不可删事实）/ 待确认 / 计划修订 三栏；完整只追加事件流；离线/迟到/代行标记 |
| 验收说明 | 逐条验收路径 |

## 核心安全语义（产品红线）

1. **视频/音频播放时间 ≠ 人员完成疏散**。每个阶段的完成条件是若干条 gate，只有被授权
   责任人在 UI 上「人工放行确认」才算发生。时间线走完不会自动放行任何 gate。
2. **两种推进模式**
   - *主持人事件推进*：阶段进入全部由主持人手动发令；
   - *统一时钟推进*：按脚本计划时长到时自动“进入”下一阶段（时间线滚动），但 gate
     仍全部需要人工确认；自动进入只物化展示事件，绝不触发完成判断。
3. **暂停**：主持人可暂停，时间线与现场确认同时挂起，只能由主持人「人工放行恢复」。
4. **超时**：阶段超过 `timeoutSec` 只产生脉冲提醒，**不自动推进、不自动放行、不替代
   现场负责人判断**。
5. **事实不可撤销**：事件日志只追加。删除草案（撤销编排）不影响任何执行记录；不能
   回退阶段；重复确认被拒绝。
6. **新版本只在批准的切换点生效**：运行中不能直接换脚本；计划切换后，跨切换点边界时
   生效，已执行阶段保留旧版本事实。没有后续切换点时给出“本场不生效”提示。
7. **唯一推进权**：主持端心跳（5s）。两人争用时第二人收到 409；持权端崩溃后，心跳
   超时（默认 15s）他人才可「接管」，接管事件写台账。页面上的「💥 模拟崩溃」按钮
   会真正停止本端心跳用于验收。
8. **离线与重连**：
   - 现场页断网后基于最近缓存显示暂定阶段并标注缓存时间，禁止把缓存当作现场实况；
   - 断网期间的放行确认带 `clientEventId` 存入本机，重连自动 POST 去重上报；
   - 若上报时阶段已推进/场次已结束 → 标记 **迟到**：事实保留，不回改当时状态；
   - 完全离线：下载单文件 HTML 播放包（资源内嵌 base64），可在本机做确认并导出
     JSON 确认文件，联网后由主持端导入。
9. **提示音缺失**：播放失败/缺失必须点「登记」，出现持续警示与台账记录，系统只提示
   改用人工口令/哨音，不自动替代。
10. **导出**：`.html` 播放包 + `.json` 清单；清单含资源依赖及嵌入状态、全部人工核对项。
    不可达外链与缺失本地资源自动进入人工核对清单。

## API 摘要

- `GET/POST /api/scripts`，`PUT /api/scripts/:id/versions/:vid/content`（仅草案）
- `POST …/revise | submit | approve | reject`；`DELETE …/versions/:vid`（仅未使用草案）
- `GET /api/scripts/:id/diff?from=&to=`
- `POST /api/scripts/:id/runs`（body `mode: host|clock`，仅已批准版本）
- `GET /api/runs/:runId`；`…/claim|heartbeat|simulate-crash|command|confirm|offline-events|audio-missing|notes|plan-switch|cancel-switch`
- `GET /api/scripts/:id/export[&manifest=1]`

## 技术说明

- 后端：Express + 本地 JSON（无外部数据库）；前端：原生 JS 单页；离线包：零网络请求单 HTML。
- `/assets/alert.wav` 为服务器合成的短促蜂鸣，既作为静态资源内嵌进播放包，也保留动态路由兜底。
